Thoughtfall CLI
Extract the whole archive and add its directory to PATH.
Run: thoughtfall capture
Uses VISUAL, then EDITOR; otherwise Notepad (Windows), nano or vi (Linux).
Example: EDITOR="code --wait" (configure GUI editors to wait).
Save and close the editor to submit; leave blank to cancel.
Release diary: ~/.thoughtfall/data.db3, shared with the desktop app.
Failed captures retain a draft and print its recovery path.
Linux needs standard .NET native runtime libraries, but no graphical desktop.
Bundled desktop launcher on Linux: thoughtfall-gui --capture
