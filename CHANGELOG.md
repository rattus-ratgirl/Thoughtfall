# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
and is generated by [Changie](https://github.com/miniscruff/changie).


## 0.1.4 - 2026-10-26
### Added
* Publish self-contained Linux installers for x64 and ARM64 alongside the Windows installer, targeting Ubuntu 24.04/26.04 and Debian 12/13.
### Fixed
* Allow the Avalonia designer to initialize Thoughtfall and construct its windows without starting desktop services or accessing diary data or settings.
* Start quietly in the system tray when supported, keep Thoughtfall running when capture is closed, and make the Windows capture shortcut available before capture is first opened.

## 0.1.3 - 2026-10-25
### Added
* Windows global capture shortcut, defaulting to Ctrl+Alt+J, with a dialog to change or disable it.
* Add Forest and Hearth colour schemes with saved System, Light and Dark appearance settings. Appearance mode applies on Save; colour-scheme changes apply on the next launch.
### Changed
* Keep Debug data and settings beside the executable, separate from Release data in the user's home directory.
* Select the release version bump in GitHub Actions and publish collected Changie notes after tests pass, committing the updated changelog and removed fragments.

## 0.1.2 - 2026-10-25
### Added
* Windows global capture shortcut, defaulting to Ctrl+Alt+J, with a dialog to change or disable it.

## 0.1.1 - 2026-10-25
### Changed
* Markdown exports now show your notes under simple year, month, and day headings, with dates formatted for your region.
