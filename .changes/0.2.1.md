## 0.2.1 - 2026-11-06
### Added
* Allow colour themes to define any number of named palettes, with one or two designated for Match System. Colour scheme and palette changes now apply without restarting.
* Add Catppuccin's Latte, Frappé, Macchiato, and Mocha palettes with Mauve accents and Latte/Mocha system matching. Forest is now the default theme; saved choices are preserved.
* Add a persistent capture text size setting in Appearance, with sizes from 10 to 24 and changes applied when saved.
* Add Everforest Soft Light and Soft Dark palettes with system appearance matching.
* Scroll upwards in capture to browse a continuous stream of read-only previous entries, with muted text, localised date and time stamps, and faint dividers. Continue scrolling past a brief hint to reveal history without leaving the current draft.
